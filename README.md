<h2 align="center">🚀 Projetos em Destaque</h2>

<h3>🍞 ValiBread (3IRMÃOS)</h3>

> **Descrição:** Sistema industrial de controle de estoque para panificadora com integração IoT/RFID (ESP32 + leitor MFRC522) e lógica **FEFO** (First Expired, First Out), garantindo o uso correto dos insumos por prazo de validade.
>
> **Destaques:** Dashboards analíticos em tempo real, leitura de tags RFID via hardware embarcado e comunicação com backend via API RESTful.
>
> **Tecnologias:** React, Node.js, Express, PostgreSQL (Azure), ESP32, MFRC522
>
> **Meu Papel:** Liderança técnica e desenvolvimento Full Stack (front-end, back-end e integração IoT).

---

<h3>🌿 GreenMind</h3>

> **Descrição:** Plataforma web gamificada voltada para educação ambiental, com trilhas interativas e acompanhamento de progresso individual dos usuários.
>
> **Destaques:** Mecânicas de gamificação, sistema de pontuação e progresso, interface responsiva e acessível.
>
> **Tecnologias:** React, Node.js, Express, MySQL
>
> **Meu Papel:** Desenvolvimento Full Stack — arquitetura do sistema, design de banco de dados e implementação das trilhas interativas.

---

<h3>♻️ ECOSELECT</h3>

> **Descrição:** Plataforma web para localização e mapeamento de pontos de coleta seletiva, utilizando mapas interativos e dados georreferenciados.
>
> **Destaques:** Integração com OpenStreetMap via Leaflet, busca por geolocalização e visualização de pontos de coleta em mapa dinâmico.
>
> **Tecnologias:** React, Leaflet, OpenStreetMap, JavaScript
>
> **Meu Papel:** Desenvolvimento Front-end e integração com APIs de mapas.
